Put the server's address in front, for example http://192.168.1.10:8000/guard. The Home page (/) shows it. On cable and Wi-Fi, use the address of your network.

Install and sign in

Server PC · once

Run QueueSetup.exe and approve the administrator prompt. The server then starts with Windows and a Queue System icon appears on the Desktop. Setup also offers to make this PC's network address fixed, so station links never change: keep the suggested option unless your network person gives you a specific address. To undo it later, use Use automatic IP in the Start Menu. If Windows shows a blue “protected your PC” box, click More info, then Run anyway.

Every other device: open the server address, click Sign in, then click Install in the top bar to add an icon.

2 · Display playlist tab

  • Upload video adds MP4, M4V or WebM files, up to 1 GB each.

3 · Announcements tab

  1. Click New announcement.
  2. Fill in Title (the orange banner), an optional Subtitle, and the Message. Each line you type becomes its own row. A live preview sits beside the form.

Switch an announcement on or off from the list. Set how long each one shows (5–120 seconds, default 15) at the top of the tab.

Chapter 3

Issue tickets

Open the day, then one tap per customer. Use Chrome on an Android phone for the best result.

Each morning

  1. Sign in at /guard.
  2. Tap Start new day (reset numbers to 001), then Start new day. Leftover tickets are archived, numbering restarts at 001, and every counter is cleared. Numbers never reset on their own.
  3. Tap Connect printer and pick your 58 mm Bluetooth printer. Once connected, every ticket prints automatically.

For each customer

  1. Tap the card for the customer's service. The number on the left is the ticket letter, the number on the right is how many are waiting.
  2. The Ticket issued window shows the number. If a printer is connected it prints by itself. If not, tap Browser print.
  3. Tap Done and hand over the ticket.

No Bluetooth printer? Browser print opens the print dialog, already sized for a 58 mm roll.

Tapped the wrong card

  • In the ticket window, tap Wrong button? Void this ticket, then confirm with Void R-005.
  • Later, find it under Issued from this device and tap Void. This works only while the customer is still waiting. Once called, it shows Already called.
  • If it was the latest number, that number is issued again to the next customer.

See who is waiting

Open Customers in line to list every waiting ticket with the time it was issued.

!Starting a new day closes every ticket still waiting or being served. Do it before the first customer, not during service.

Chapter 4

Serve customers

Press Next customer. Everything else follows from there.

The service loop

  1. Sign in. You land on your counter's page, for example /counter/1.
  2. Press Next customer. The number appears under Now serving, and the TV flashes, chimes and speaks it.
  3. Serve the customer, then press Complete.
  4. Press Next customer again.

To call someone specific, press Call beside their number in the Waiting list. The top row is marked Next.

Mini window and covering a partner

A small strip with only the buttons you use all day, and a way to keep customers moving when a counter closes.

Open the mini window

  • On the counter page, click Mini window. If nothing opens, allow pop-ups for the site in the address bar.
  • On Windows, double-click the Counter N - Mini Desktop icon. It stays on top of other programs and can start with Windows.

Transfer several customers at once

  1. Choose More → Transfer customers… The customer at the counter is already ticked.
  2. Tick the others, or use All / None.
  3. Under Send to, pick Regular, Priority or Request / Complaint.

Closing a counter: pause and cover

Counters 1 and 2 cover each other. Counter 3 cannot be paused.

  1. Press Pause counter (or Pause in the mini window). The TV shows On Break · Please proceed to Counter N.
  2. The partner counter shows a green Covering for… banner. Its Next customer now calls both lines, Priority first, or by the pattern if you enabled load balancing.
  3. When you return, press Resume counter.
iThe status line under the mini buttons shows confirmations and warns Lost connection to the queue server. Reconnecting… if the link drops.

Chapter 6

The waiting-room TV

Customers watch this screen. Staff only need to set it up once.

Set up the TV

  1. Open /display in the TV's browser and go full screen. No sign-in is needed.
  2. Click the screen once, or press any remote key, to switch on sound. Browsers require this after every restart.
  3. Sound is controlled only from Admin → Settings → TV display sound. There is no mute button on the TV.

When a customer is called

  • The counter's card flashes amber, a chime plays, and a voice reads the number and counter, for example “Now serving ticket R-023, please proceed to Counter 1.”
  • Recall repeats the announcement.
  • Video volume drops for a few seconds while the call plays.

Quick fixes

ProblemTry this
Red Reconnecting badge staysCheck the Wi-Fi or cable, and that the server PC is on.
TV has no soundClick the TV screen once. Check TV display sound is on in Admin → Settings, then the TV volume.
Printer won't connectUse Chrome on Android, with Bluetooth and the printer on. Or use Browser print.
Mini window won't openAllow pop-ups for the site in the address bar, then try again.
Can't sign inCheck the username and password. A counter account opens only its own counter. Ask the admin.
Server stopped respondingOn the server PC: Start menu → Queue System → Restart queue server. Server log is in the same folder.
Wrong ticket was printedVoid it from the Guard screen while the customer is still waiting.
